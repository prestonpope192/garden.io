## Working practices (for the next agent)

- **Authed preview:** the app is behind a magic-link `AuthGate`. Mint a
  session for fixture `plotmap-preview@garden.test` (Thornfield Garden,
  zone 7a): service-role `admin.generateLink({type:"magiclink"})` →
  `verifyOtp` with the `hashed_token` → derive the `sb-<ref>-auth-token`
  cookie via `createServerClient` `setAll` capture → inject via
  `document.cookie` in the preview. Alternative:
  `/auth/confirm?token_hash=<hashed_token>&type=magiclink` works end-to-end.
  Never write tokens under `website/public/`; delete mint scripts and
  cookie files immediately after use.
- **Unauthenticated fallback:** `/tour/{ask,property,calendar,plants,catalogue}`
  (demo data; safe local interactions only, no persistence).
- **Test mutations:** prefer reversible in-UI actions (task done → Undo);
  otherwise create-then-delete via service role with a recognizable marker
  string.
- **Gates before claiming done:** `npm test` && `npm run typecheck` &&
  `npm run build` from `website/`; `npm run test:browser` when browser/CI
  paths changed.
- Sandbox note: the mint script needs outbound network — the default Bash
  sandbox blocks DNS.
