# Prototype Botanical Art Notes

These `website/public/art/*.svg` assets are the current committed specimen-style illustration set for the clickable notebook prototype.

Intent:
- sepia and charcoal botanical plate language
- consistent line weight and paper tone
- decorative support only, never required for comprehension

Current implementation choice:
- local SVG studies created directly in-repo for this prototype pass
- normalized to one visual system so the landing page and `/app*` routes share the same art language

Future art pipeline:
- replace or augment these files with curated AI-assisted or custom botanical artwork once a formal provenance and approval process exists
- preserve the same sizing, contrast, and sepia treatment so components do not need to change
